# ASHEN CROWN — Game Design Document

A dark medieval fantasy RPG about Kael Varyn, a man marked by tragedy, travelling through a fractured realm. The atmosphere is serious and moody, with occasional lighthearted character moments.

## Pillars
- Classic top-down JRPG exploration inspired by the original Final Fantasy (1987), not side-view.
- Menu-driven turn-based battles; planned four-character party.
- Preparation matters: levels, equipment, party order, and tactics should matter. No automatic enemy scaling by default.
- Pixel art, evocative locations, strong silhouettes, readable UI.

## Core loop
Explore → interact → encounter → choose commands → resolve turns → earn rewards → recover/upgrade → unlock a route.

## Planned features
Top-down movement and collision; NPC/object interactions; turn-based combat; equipment, party order, items, save/load, character status, and Bestiary.

## First vertical slice
One small overworld map, placeholder player, one interaction, battle against Bandit or Fallen Knight, victory/defeat, and reliable return to exploration.

This repository is a starter/documentation package, not a complete runnable GameMaker project. GML snippets require IDE integration and testing.
