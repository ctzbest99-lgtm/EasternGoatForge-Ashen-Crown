## B. Critical error report

### CRITICAL-1 — reserved keyword used as a struct key (fixed)

`game/scripts/scr_wf_markers_data.gml:35` (Wrenfield markers, generated export)
built a marker struct containing `then: "WF_CALDER_INTRO_01"`. `then` is a real
GML keyword — the manual documents `if (<expr>) then { ... }` — so it is reserved
and cannot be an identifier or struct key. Every GML parser rejects the line, and
GameMaker would too. This alone would fail compilation of the project.

Repair: renamed the field to `then_script`. The key had no readers (no `.then`
access, no `"then"` string lookup anywhere in `game/`), so the rename changes no
behaviour and leaves the intent — the script that follows the story trigger —
documented in the data.

### CRITICAL-2 — brace block directly after a `case` label (fixed)

`game/scripts/scr_encounter_tables.gml:188` opened the `grp_reeve_calder` arm as
`case "grp_reeve_calder": { ... }`. A braced block in that position is rejected by
the GML grammar used for verification, and it is the only arm in the file written
that way. Since the arm ends in `return`, removing the braces is a pure
de-indentation: same statements, same control flow, no fallthrough risk.
