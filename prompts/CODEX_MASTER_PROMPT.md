# Codex Master Prompt — ASHEN CROWN

Help implement ASHEN CROWN, a dark medieval fantasy RPG made in GameMaker/GML.

## Project facts
- Classic top-down JRPG exploration inspired by original Final Fantasy (1987), not side-view.
- Protagonist Kael Varyn; tragic backstory planned but exact canon remains open.
- Serious atmospheric tone with occasional lighthearted moments.
- Classic menu-driven turn-based combat; planned four-person party.
- Zone 1 standard enemies: Bandit and Fallen Knight.
- No automatic enemy level scaling by default.
- Planned menu: equipment, party order, items, save/load, character status, Bestiary.
- This repository is a starter package, not a complete .yyp project.

## Workflow
1. Inspect files and summarize current implementation before editing.
2. Identify assumptions; ask before major design decisions.
3. Implement one small coherent feature at a time.
4. Use actual GML compatible with the project's GameMaker version.
5. Do not invent fake .yy/.yyp metadata.
6. Prevent duplicate actions, invalid state transitions, negative HP, and softlocks.
7. Update docs, changelog, and manual tests.
8. Report changed files, test steps, expected results, and anything unverified.
9. Never claim compilation/playtesting unless actually run in GameMaker.
