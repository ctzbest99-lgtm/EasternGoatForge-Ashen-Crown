# ASHEN CROWN

A dark medieval fantasy RPG by Eastern Goat Forge, built with GameMaker and GML.

**Direction:** classic top-down JRPG exploration inspired by the original *Final Fantasy* (not side-view), with menu-driven turn-based combat and a planned four-character battle party.

**Status:** pre-production starter. This repository is not yet a complete runnable `.yyp` project. Code samples must be integrated into GameMaker and tested there.

## Confirmed concepts
- Protagonist: Kael Varyn; tragic backstory is part of the concept.
- Tone: dark, atmospheric, serious, with occasional lighthearted moments.
- Zone 1 enemies: Bandit and Fallen Knight.
- Planned systems: exploration, interactions, turn-based combat, menus, equipment, party order, items, save/load, character status, and Bestiary.
- Art direction: pixel art with a 32×48 player reference planned. Earlier image assets are not automatically present in this repository.
